
# AI-Powered Resume Analyzer

An AI-powered web application built using Python and Streamlit to analyze resumes and compare skills against job descriptions.

## Features
- Upload PDF resumes
- Extract resume text
- Detect technical skills
- Match skills with job descriptions
- Calculate skill match percentage
- Generate AI-powered feedback
- Analyze education and contact details
- Download analysis reports

## Technologies Used
- Python
- Streamlit
- PyPDF
- Ollama
- Llama 3.2 (3B)

## Installation

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Install Ollama and download the model:

   ollama pull llama3.2:3b

4. Run the application:

   python -m streamlit run app.py
